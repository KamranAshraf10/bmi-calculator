# BMI Calculator

A simple web-based BMI (Body Mass Index) Calculator that allows users to input their height and weight and calculate their BMI. The application categorizes the user as **Underweight**, **Healthy**, **Overweight**, or **Obese** based on the calculated BMI.

## Features

- Calculate BMI based on height (cm) and weight (kg).
- Displays the calculated BMI value.
- Provides health status (Underweight, Healthy, Overweight, Obese).
- Responsive and user-friendly design.
